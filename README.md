# Interstellar V7
[![FOSSA Status](https://app.fossa.com/api/projects/git%2Bgithub.com%2Fmarkwi0981-netizen%2FInterstellar-Astro-idk.svg?type=shield)](https://app.fossa.com/projects/git%2Bgithub.com%2Fmarkwi0981-netizen%2FInterstellar-Astro-idk?ref=badge_shield)


Web proxy with multi-tab browser interface.

## Deployment

```bash
git clone https://github.com/UseInterstellar/Interstellar-Astro
cd Interstellar-Astro
bun install && bun start
```

## Development

```bash
bun install && bun dev
```

## Tech Stack

- Astro 5 + React 19
- Fastify backend
- Scramjet proxy engine
- Tailwind CSS
